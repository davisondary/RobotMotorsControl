# RobotMotorsControl

## Общее описание проекта

RobotMotorsControl — учебный проект с программой для управления двигателями робота. Цель проекта — освоить основные возможности системы контроля версий Git: создание и клонирование репозитория, сохранение изменений, работа с ветками и создание пул-реквестов.

Программа написана на Python. Она имитирует управление левым и правым двигателями, плавное увеличение их скорости и последующую остановку.

## Возможности программы

* установка скорости левого и правого двигателей;
* плавное увеличение скорости от 0 до 50%;
* задержка между изменениями скорости;
* остановка обоих двигателей;
* вывод информации о работе двигателей в терминал.

## Запуск программы

Для запуска необходимо выполнить команду:

```bash
python3 motors_control.py
```

## Создание и клонирование репозитория

Репозиторий `RobotMotorsControl` был создан на платформе GitHub. При создании был добавлен файл README.md.

Репозиторий был клонирован на компьютер командой:

```bash
git clone https://github.com/davisondary/RobotMotorsControl.git
```

После клонирования работа выполнялась в локальной папке проекта.

## Сохранение изменений

Для добавления, фиксации и отправки изменений использовались команды:

```bash
git add motors_control.py
git commit -m "Добавлен базовый скрипт управления двигателями"
git push origin main
```

Команда `git add` добавила файл в индекс, `git commit` сохранила изменения в локальном репозитории, а `git push` отправила коммит на GitHub.

## Работа с ветками

Для разработки новой функции была создана отдельная ветка:

```bash
git checkout -b feature-smooth-speed
```

В этой ветке была реализована функция плавного изменения скорости двигателей. После проверки программы изменения были сохранены и отправлены на GitHub:

```bash
git add motors_control.py
git commit -m "Добавлено плавное изменение скорости двигателей"
git push -u origin feature-smooth-speed
```

## Пул-реквест

На GitHub был создан пул-реквест из ветки `feature-smooth-speed` в основную ветку `main`.

В описании пул-реквеста были перечислены выполненные изменения. GitHub подтвердил отсутствие конфликтов, после чего пул-реквест был объединён с основной веткой и закрыт.

## Основные изменения и улучшения

В проект была добавлена функция `change_speed_smoothly`. Она постепенно увеличивает скорость обоих двигателей от 0 до 50% с небольшой задержкой между этапами.

После достижения заданной скорости вызывается функция остановки двигателей. Работа программы была проверена в Ubuntu.
